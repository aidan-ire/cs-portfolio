# Factorial Sigma

Reads `n` and prints 1! + 2! + ... + n!, with the factorial of each term worked out in an inner loop. `n` is limited to 20, the largest that fits in a `long`.

## Run

```bash
javac FactorialSigma.java
java FactorialSigma
```

## Example run

```
Please input a number from 1 to 20: 5
Sum of 1! to 5! = 153
```
