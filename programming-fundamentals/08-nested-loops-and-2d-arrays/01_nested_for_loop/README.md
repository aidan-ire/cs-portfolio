# Nested For Loop

Reads a size `n` and prints an `n` by `n` multiplication table.

## Run

```bash
javac NestedForLoop.java
java NestedForLoop
```

## Example run

```
Please input the size of the table: 5
   1   2   3   4   5
   2   4   6   8  10
   3   6   9  12  15
   4   8  12  16  20
   5  10  15  20  25
```
