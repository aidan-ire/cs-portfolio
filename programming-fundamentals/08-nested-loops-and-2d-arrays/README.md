# Lab 08: Nested loops and 2D arrays

Exercises on nested loops over tables and grids, 2D arrays and flattening. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Nested For Loop | [01_nested_for_loop](01_nested_for_loop/) | Reads a size `n` and prints an `n` by `n` multiplication table. |
| 2. Nested While Loop | [02_nested_while_loop](02_nested_while_loop/) | Reads a number of rows and prints a triangle where row `i` counts from 1 to `i`. |
| 3. Smallest Row | [03_smallest_row](03_smallest_row/) | Adds up each row of a fixed 4 by 3 array and prints the row with the smallest total, with its index, sum and values. |
| 4. Fill Diagonal | [04_fill_diagonal](04_fill_diagonal/) | Reads a size `n`, makes an `n` by `n` array of zeros, sets the main diagonal to 1 and prints it. |
| 5. Factorial Sigma | [05_factorial_sigma](05_factorial_sigma/) | Reads `n` and prints 1! + 2! + ... + n!, with the factorial of each term worked out in an inner loop. `n` is limited to 20, the largest that fits in a `long`. |
| 6. Array 2D Array 1D | [06_array_2d_array_1d](06_array_2d_array_1d/) | Copies a fixed 3 by 4 array into a 1D array of 12 values, row by row, and prints the 1D array. |
