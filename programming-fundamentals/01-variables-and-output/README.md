# Variables and output

Exercises on printing, variables, arithmetic and the modulus operator. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Hello World | [01_hello_world](01_hello_world/) | Prints the text `Hello World` on one line. |
| 2. The Name | [02_the_name](02_the_name/) | Stores a name in a `String` variable and prints it inside a short sentence. |
| 3. What is the Output | [03_what_is_the_output](03_what_is_the_output/) | A "predict the output" program: small expressions whose results are easy to get wrong, with the reason beside each line. |
| 4. Creating Variables | [04_creating_variables](04_creating_variables/) | One variable of each common type, declared with a value and printed with a label. |
| 5. Arithmetic | [05_arithmetic](05_arithmetic/) | Declares `num1`, `num2` and `num3` (5, 10, 15) and the result variables one per line, then prints the sum of all three, `num2 * num3`, and `num3 / num1`. |
| 6. Modulus Operator | [06_modulus_operator](06_modulus_operator/) | Splits the 4 digit `int` `num` into its digits with `%` and `/`, and prints one digit per line. `num` is 1981. |
