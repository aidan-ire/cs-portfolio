# Methods and recursion

More practice with methods, overloading and recursion. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Find SubStrings | [01_find_substrings](01_find_substrings/) | Lists every index where a substring starts in a string, including overlapping matches. |
| 2. Exponent | [02_exponent](02_exponent/) | Raises a number to a power recursively, halving the exponent on each call. |
| 3. Method Overloading 2 | [03_method_overloading_2](03_method_overloading_2/) | Three `area` methods for a circle, a rectangle and a triangle, chosen by the number of arguments. |
| 4. Reciprocals | [04_reciprocals](04_reciprocals/) | Sums 1/1 + 1/2 + … + 1/n recursively to 4 decimal places. |
| 5. Remove Odds | [05_remove_odds](05_remove_odds/) | Returns a new array holding only the even numbers. |
