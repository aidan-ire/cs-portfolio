# Reciprocals

Reads n and prints 1/1 + 1/2 + … + 1/n to 4 decimal places. The sum is worked out recursively.

## Run

```bash
javac Reciprocals.java
java Reciprocals
```

## Example runs

```
Please input n: 1
1/1 = 1.0000
```

```
Please input n: 4
1/1 + 1/2 + 1/3 + 1/4 = 2.0833
```

```
Please input n: 1000
1/1 + 1/2 + ... + 1/1000 = 7.4855
```
