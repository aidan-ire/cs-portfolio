# Remove Odds

Reads an array and returns a new array with only the even numbers, in their original order. The original array is left as it was.

## Run

```bash
javac RemoveOdds.java
java RemoveOdds
```

## Example runs

```
Please input the number of values: 8
Please input the values: 3 8 -2 7 10 0 5 -9
Before: [3, 8, -2, 7, 10, 0, 5, -9]
After:  [8, -2, 10, 0]
```

```
Please input the number of values: 3
Please input the values: 1 3 5
Before: [1, 3, 5]
After:  []
```
