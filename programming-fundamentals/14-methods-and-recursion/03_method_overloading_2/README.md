# Method Overloading 2

Three `area` methods that differ in how many parameters they take: one is a circle's radius, two are a rectangle's sides, and three are a triangle's sides (using Heron's formula). Sides that can't form a triangle give an area of 0. The program takes no input.

## Run

```bash
javac MethodOverloading2.java
java MethodOverloading2
```

## Example run

```
Circle, radius 2.5:          19.63
Rectangle, 4 by 6.5:         26.00
Triangle, sides 3, 4 and 5:  6.00
Triangle, sides 1, 2 and 10: 0.00
```
