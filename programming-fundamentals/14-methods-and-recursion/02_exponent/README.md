# Exponent

Raises a base to a whole-number exponent with a recursive `power` method. The exponent is halved on each call, using x^n = (x^(n/2))².

## Run

```bash
javac Exponent.java
java Exponent
```

## Example runs

```
Please enter base and exponent respectively: 2 10
2^10 = 1024
```

```
Please enter base and exponent respectively: -3 5
(-3)^5 = -243
```

```
Please enter base and exponent respectively: 7 0
7^0 = 1
```
