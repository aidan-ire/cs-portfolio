# Keyboard input

Exercises on reading numbers, words and lines with `Scanner`. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Integer Inputs | [01_integer_inputs](01_integer_inputs/) | Reads two integers with `Scanner` and prints their sum. |
| 2. String Inputs | [02_string_inputs](02_string_inputs/) | Reads a first name and a surname on separate lines and prints a greeting using both. |
| 3. Four Times | [03_four_times](03_four_times/) | Reads a word and prints it four times on one line, separated by spaces. |
| 4. Text Speak | [04_text_speak](04_text_speak/) | Replaces whole words from a small fixed list (`you` to `u`, `are` to `r`, `for` to `4`, `to` to `2`, and a few more) and leaves every other word as it was. A word with punctuation attached, like `you,`, is not replaced. |
| 5. Area of a Rectangle | [05_area_of_a_rectangle](05_area_of_a_rectangle/) | Reads a length and a width as decimal numbers and prints length times width. |
| 6. Larger Numbers | [06_larger_numbers](06_larger_numbers/) | Reads two integers and prints the larger, or says they are equal. |
| 7. License Plates | [07_license_plates](07_license_plates/) | Reads a plate in the form `191-D-12345` and prints the year (the first two digits after `20`), the half of the year (a `1` or `2` as the third digit), the county code and the number. Only the three digit form is handled. |
| 8. The Middle Number | [08_the_middle_number](08_the_middle_number/) | Reads three integers and prints the one that is neither the largest nor the smallest, using comparisons and no sorting. |
