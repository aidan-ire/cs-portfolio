# The Middle Number

Reads three integers and prints the one that is neither the largest nor the smallest, using comparisons and no sorting.

## Run

```bash
javac TheMiddleNumber.java
java TheMiddleNumber
```

## Example runs

```
Please input three numbers: 3 9 5
The middle number is 5
```

```
Please input three numbers: 9 5 3
The middle number is 5
```

```
Please input three numbers: 5 9 3
The middle number is 5
```
