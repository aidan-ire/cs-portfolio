# Larger Numbers

Reads two integers and prints the larger, or says they are equal.

## Run

```bash
javac LargerNumbers.java
java LargerNumbers
```

## Example runs

```
Please input two numbers: 8 3
The larger number is 8
```

```
Please input two numbers: 3 8
The larger number is 8
```

```
Please input two numbers: 5 5
The numbers are equal
```
