# Text Speak

Replaces whole words from a small fixed list (`you` to `u`, `are` to `r`, `for` to `4`, `to` to `2`, and a few more) and leaves every other word as it was. A word with punctuation attached, like `you,`, is not replaced.

## Run

```bash
javac TextSpeak.java
java TextSpeak
```

## Example runs

```
Please input a sentence: See you later and be great
c u l8r n b gr8
```

```
Please input a sentence: Why are you late
y r u late
```
