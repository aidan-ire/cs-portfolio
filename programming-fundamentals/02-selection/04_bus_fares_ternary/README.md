# Bus Fares Ternary

Reads an age and sets the fare with chained `? :` operators. Under 5 and 66 or over travel free, under 18 pay 1.50, everyone else pays 3.00.

## Run

```bash
javac BusFaresTernary.java
java BusFaresTernary
```

## Example runs

```
Please input an age: 30
Fare: 3.00 euro
```

```
Please input an age: 12
Fare: 1.50 euro
```

```
Please input an age: 70
Fare: 0.00 euro
```
