# Drivers License Categories

Uses `if` statements on a `char` variable `license` to print the vehicle the license allows: `a` motorcycle, `b` car, `c` truck, `d` bus.

`license` is set in the code (`a`). Any other value prints `Invalid license`.

## Run

```bash
javac DriversLicenseCategories.java
java DriversLicenseCategories
```

## Example run

```
Motorcycle
```
