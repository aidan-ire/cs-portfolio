# Fizz Buzz 1

Reads one number and prints `Fizz` if it divides by 3, `Buzz` if by 5, `FizzBuzz` if by both, otherwise the number itself.

## Run

```bash
javac FizzBuzz1.java
java FizzBuzz1
```

## Example runs

```
Please input a number: 9
Fizz
```

```
Please input a number: 10
Buzz
```

```
Please input a number: 30
FizzBuzz
```

```
Please input a number: 7
7
```
