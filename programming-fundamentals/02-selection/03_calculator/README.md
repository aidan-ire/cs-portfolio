# Calculator

Reads two numbers and one of `+ - * /`, chooses with `if` statements and prints the result. Division by zero and an unknown operator print a message.

## Run

```bash
javac Calculator.java
java Calculator
```

## Example runs

```
Please input two numbers: 6 3
Please input an operator (+, -, *, /): /
Result: 2.0
```

```
Please input two numbers: 5 0
Please input an operator (+, -, *, /): /
Cannot divide by zero
```
