# Selection

Exercises on `if` statements, the ternary operator and decisions on numbers. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Retirement Age | [01_retirement_age](01_retirement_age/) | Prints whether a person is retired, which is true from age 66. `age` is an `int`. |
| 2. Drivers License Categories | [02_drivers_license_categories](02_drivers_license_categories/) | Uses `if` statements on a `char` variable `license` to print the vehicle the license allows: `a` motorcycle, `b` car, `c` truck, `d` bus. |
| 3. Calculator | [03_calculator](03_calculator/) | Reads two numbers and one of `+ - * /`, chooses with `if` statements and prints the result. Division by zero and an unknown operator print a message. |
| 4. Bus Fares Ternary | [04_bus_fares_ternary](04_bus_fares_ternary/) | Reads an age and sets the fare with chained `? :` operators. Under 5 and 66 or over travel free, under 18 pay 1.50, everyone else pays 3.00. |
| 5. Leap Years | [05_leap_years](05_leap_years/) | Reads a year and applies the Gregorian rule: divisible by 4, except century years unless they are divisible by 400. |
| 6. Fizz Buzz 1 | [06_fizz_buzz_1](06_fizz_buzz_1/) | Reads one number and prints `Fizz` if it divides by 3, `Buzz` if by 5, `FizzBuzz` if by both, otherwise the number itself. |
