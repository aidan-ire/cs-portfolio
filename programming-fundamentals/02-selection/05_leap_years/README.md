# Leap Years

Reads a year and applies the Gregorian rule: divisible by 4, except century years unless they are divisible by 400.

## Run

```bash
javac LeapYears.java
java LeapYears
```

## Example runs

```
Please input a year: 2024
2024 is a leap year
```

```
Please input a year: 1900
1900 is not a leap year
```
