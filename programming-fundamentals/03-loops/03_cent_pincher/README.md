# Cent Pincher

Paddy saves 1 cent on day 1 and doubles the amount each day. Reads the `int` `days` and uses a `while` loop to add up the total saved by the end of that day.

The total is a `long`, so it is correct up to day 62.

## Run

```bash
javac CentPincher.java
java CentPincher
```

## Example runs

```
2
3
```

```
3
7
```
