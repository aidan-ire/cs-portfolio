# Prime Number Checker

Reads a number and tests divisors up to its square root. 0, 1 and negatives are not prime.

## Run

```bash
javac PrimeNumberChecker.java
java PrimeNumberChecker
```

## Example runs

```
Please input a number: 29
29 is prime
```

```
Please input a number: 91
91 is not prime
```
