# Divisors

Reads a positive number and prints every number from 1 up to it that divides it exactly, on one line.

## Run

```bash
javac Divisors.java
java Divisors
```

## Example runs

```
Please input a positive number: 12
Divisors of 12: 1 2 3 4 6 12
```

```
Please input a positive number: 7
Divisors of 7: 1 7
```
