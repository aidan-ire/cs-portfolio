# Break Palindromic Numbers

Reads a start number and counts up in a loop until it finds the first palindromic number at or above it, then uses `break` to stop.

## Run

```bash
javac BreakPalindromicNumbers.java
java BreakPalindromicNumbers
```

## Example runs

```
Please input a number: 123
The first palindromic number from 123 is 131
```

```
Please input a number: 99
The first palindromic number from 99 is 99
```
