# Loops

Exercises on `for` and `while` loops, `break`, and counting patterns. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Count Up and Down | [01_count_up_and_down](01_count_up_and_down/) | Reads `n`, prints 1 up to `n` and then `n - 1` down to 1, one number per line, so `n` appears once. |
| 2. Fizzbuzz 2 | [02_fizzbuzz_2](02_fizzbuzz_2/) | Loops from 1 to 100 and prints `Fizz`, `Buzz`, `FizzBuzz` or the number for each, one per line. |
| 3. Cent Pincher | [03_cent_pincher](03_cent_pincher/) | Paddy saves 1 cent on day 1 and doubles the amount each day. Reads the `int` `days` and uses a `while` loop to add up the total saved by the end of that day. |
| 4. Divisors | [04_divisors](04_divisors/) | Reads a positive number and prints every number from 1 up to it that divides it exactly, on one line. |
| 5. Prime Number Checker | [05_prime_number_checker](05_prime_number_checker/) | Reads a number and tests divisors up to its square root. 0, 1 and negatives are not prime. |
| 6. Break Palindromic Numbers | [06_break_palindromic_numbers](06_break_palindromic_numbers/) | Reads a start number and counts up in a loop until it finds the first palindromic number at or above it, then uses `break` to stop. |
