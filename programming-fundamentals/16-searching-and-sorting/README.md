# Searching and sorting

Selection, insertion and bubble sorts written by hand (no `Arrays.sort`), plus binary search used two ways: to find a gap in sorted data, and as a guessing game. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Alphabetical | [01_alphabetical](01_alphabetical/) | Sorts a line of words alphabetically with a selection sort, ignoring case. |
| 2. Anagram | [02_anagram](02_anagram/) | Sorts the letters of two phrases with an insertion sort and compares them. |
| 3. MissingElement | [03_missing_element](03_missing_element/) | Finds the number missing from 1 to n with an insertion sort followed by a binary search. |
| 4. Binary Search Game | [04_binary_search_game](04_binary_search_game/) | Guesses the user's number from 1 to 100 in at most 7 tries by halving the range. |
| 5. WordBuilder | [05_word_builder](05_word_builder/) | Builds a word letter by letter until `done`, then bubble sorts its letters. |
| 6. Bubble Sort Integers | [06_bubble_sort_integers](06_bubble_sort_integers/) | Bubble sorts an array, showing each pass and counting swaps, and stops early when a pass makes no swaps. |
| 7. Unique Sorting | [07_unique_sorting](07_unique_sorting/) | Sorts numbers with a selection sort and removes duplicates in one pass. |
