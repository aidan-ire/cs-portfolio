# WordBuilder

Builds a word one letter at a time until the user types `done`, then prints the word and its letters in alphabetical order, sorted with a bubble sort. Anything that isn't a single letter is rejected.

## Run

```bash
javac WordBuilder.java
java WordBuilder
```

## Example run

```
Type one letter at a time, then "done" to finish.
Letter: q
Word so far: q
Letter: u
Word so far: qu
Letter: 7
"7" is not a single letter
Letter: i
Word so far: qui
Letter: ck
"ck" is not a single letter
Letter: c
Word so far: quic
Letter: k
Word so far: quick
Letter: done
Your word: quick
Its letters in alphabetical order: cikqu
```
