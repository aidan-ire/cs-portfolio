# Unique Sorting

Reads some numbers, sorts them with a selection sort and removes the duplicates. After sorting, equal values sit next to each other, so a single pass drops any value that matches the one before it.

## Run

```bash
javac UniqueSorting.java
java UniqueSorting
```

## Example run

```
Please input the number of values: 10
Please input the values: 5 3 9 3 1 5 5 -2 9 0
Unique values, sorted: [-2, 0, 1, 3, 5, 9]
```
