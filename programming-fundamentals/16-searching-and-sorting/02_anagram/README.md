# Anagram

Checks whether two words or phrases are anagrams. The letters of each are sorted with an insertion sort and the sorted lists compared. Case, spaces and punctuation are ignored.

## Run

```bash
javac Anagram.java
java Anagram
```

## Example runs

```
Please input the first word or phrase: Listen
Please input the second word or phrase: Silent
"Listen" and "Silent" are anagrams
```

```
Please input the first word or phrase: Dormitory
Please input the second word or phrase: dirty room!
"Dormitory" and "dirty room!" are anagrams
```

```
Please input the first word or phrase: Dublin
Please input the second word or phrase: Mountain
"Dublin" and "Mountain" are not anagrams
```
