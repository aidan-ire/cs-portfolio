# Lab 06: Loops and strings

Exercises on nested loops, digit tricks and checks on strings. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Right Angle Triangles | [01_right_angle_triangles](01_right_angle_triangles/) | Reads a height and prints that many rows of stars, the first with one star and each row one longer than the last. |
| 2. Processing Reverse Substrings | [02_processing_reverse_substrings](02_processing_reverse_substrings/) | Reads a sentence and reverses each space separated word in place, so `hello world` becomes `olleh dlrow`. |
| 3. Sub Mirror | [03_sub_mirror](03_sub_mirror/) | Reads a word and, for each prefix of it, prints the prefix, a `|`, and the prefix reversed, so the word `abc` gives `a|a`, `ab|ba` and `abc|cba`. |
| 4. Self-Factoring Numbers | [04_self_factoring_numbers](04_self_factoring_numbers/) | Reads a limit and prints every number up to it that is divisible by each of its digits, eg. 128 (1, 2 and 8 all divide it). A number containing a 0 digit does not count. |
| 5. Module Codes | [05_module_codes](05_module_codes/) | Checks for the shape of a code like `CS161`: two capital letters then three digits. A valid code prints its department letters and the year (the first digit). |
| 6. Well Ordered | [06_well_ordered](06_well_ordered/) | A word is well ordered if its letters never go backwards through the alphabet, eg. `almost`. Case is ignored. |
