# Module Codes

Checks for the shape of a code like `CS161`: two capital letters then three digits. A valid code prints its department letters and the year (the first digit).

## Run

```bash
javac ModuleCodes.java
java ModuleCodes
```

## Example runs

```
Please input a module code: CS161
CS161 is a valid module code
Department: CS
Year: 1
```

```
Please input a module code: cs161
cs161 is not a valid module code
```

```
Please input a module code: CS16
CS16 is not a valid module code
```
