# Sub Mirror

Reads a word and, for each prefix of it, prints the prefix, a `|`, and the prefix reversed, so the word `abc` gives `a|a`, `ab|ba` and `abc|cba`.

## Run

```bash
javac SubMirror.java
java SubMirror
```

## Example runs

```
Please input a word: abc
a|a
ab|ba
abc|cba
```

```
Please input a word: java
j|j
ja|aj
jav|vaj
java|avaj
```
