# Well Ordered

A word is well ordered if its letters never go backwards through the alphabet, eg. `almost`. Case is ignored.

## Run

```bash
javac WellOrdered.java
java WellOrdered
```

## Example runs

```
Please input a word: almost
almost is well ordered
```

```
Please input a word: java
java is not well ordered
```

```
Please input a word: Billowy
billowy is well ordered
```
