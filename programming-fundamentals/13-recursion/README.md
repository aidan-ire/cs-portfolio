# Lab 04: Recursion

Each exercise is solved with a recursive method: a base case that stops the recursion, and a call on a smaller input that moves towards it. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Maths Function | [01_maths_function](01_maths_function/) | Prints f(x) = x² − 3x + 2 for x from 1 to n, recursing over x instead of looping. |
| 2. Minimum Value | [02_minimum_value](02_minimum_value/) | Finds the smallest value in an array. |
| 3. String Reverse | [03_string_reverse](03_string_reverse/) | Reverses a string. |
| 4. Sum Digits | [04_sum_digits](04_sum_digits/) | Adds up the digits of a number. |
| 5. Clean String | [05_clean_string](05_clean_string/) | Keeps only the letters of a string, in lower case. |
| 6. Count Digits | [06_count_digits](06_count_digits/) | Counts the digits in a number. |
| 7. Vowels Recursion | [07_vowels_recursion](07_vowels_recursion/) | Counts the vowels in a sentence. |
