# Clean String

Removes everything except letters from a string and converts it to lower case, one character per recursive call.

## Run

```bash
javac CleanString.java
java CleanString
```

## Example runs

```
Please input a string: Hello, World! 2026
Cleaned: "helloworld"
```

```
Please input a string: CS162 -- Lab 4: Recursion!
Cleaned: "cslabrecursion"
```
