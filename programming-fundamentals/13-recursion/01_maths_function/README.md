# Maths Function

Reads n and prints f(x) = x² − 3x + 2 for x from 1 to n. There is no loop: `printTable` prints one row, then calls itself with the next x until x passes n.

## Run

```bash
javac MathsFunction.java
java MathsFunction
```

## Example run

```
Please input n: 5
f(x) = x^2 - 3x + 2
f(1) = 0
f(2) = 0
f(3) = 2
f(4) = 6
f(5) = 12
```
