# Sum Digits

Adds up the digits of a number recursively, taking the last digit with `% 10` and passing the rest on with `/ 10`. A minus sign is ignored.

## Run

```bash
javac SumDigits.java
java SumDigits
```

## Example runs

```
Please input a number: 472
Sum of the digits of 472: 13
```

```
Please input a number: -9051
Sum of the digits of -9051: 15
```

```
Please input a number: 0
Sum of the digits of 0: 0
```
