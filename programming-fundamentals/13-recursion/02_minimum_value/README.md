# Minimum Value

Reads an array and finds its smallest value recursively. The minimum from index `i` onwards is the smaller of `arr[i]` and the minimum of the rest, and the last element is the base case.

## Run

```bash
javac MinimumValue.java
java MinimumValue
```

## Example runs

```
Please input the number of values: 6
Please input the values: 14 3 -8 22 0 5
Minimum value: -8
```

```
Please input the number of values: 1
Please input the values: 42
Minimum value: 42
```
