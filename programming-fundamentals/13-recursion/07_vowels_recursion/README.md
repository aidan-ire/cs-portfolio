# Vowels Recursion

Counts the vowels (a, e, i, o, u, in either case) in a sentence recursively. It passes an index along rather than building substrings.

## Run

```bash
javac VowelsRecursion.java
java VowelsRecursion
```

## Example runs

```
Please input a sentence: Introduction to Computer Science
Number of vowels: 12
```

```
Please input a sentence: rhythm
Number of vowels: 0
```
