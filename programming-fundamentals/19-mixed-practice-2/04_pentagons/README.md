# Pentagons

Prints the first n pentagonal numbers using the formula n(3n − 1)/2.

## Run

```bash
javac Pentagons.java
java Pentagons
```

## Example runs

```
How many pentagonal numbers? 10
The first 10 pentagonal numbers: 1 5 12 22 35 51 70 92 117 145
```

```
How many pentagonal numbers? 1
The first pentagonal number: 1
```
