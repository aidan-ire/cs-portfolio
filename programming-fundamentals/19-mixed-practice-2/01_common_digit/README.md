# Common Digit

Reads two whole numbers and prints the digits they share. A `boolean[10]` records which digits appear in each number.

## Run

```bash
javac CommonDigit.java
java CommonDigit
```

## Example runs

```
Please input two numbers: 40719 9174
Digits in both 40719 and 9174: 1 4 7 9
```

```
Please input two numbers: 2468 1357
2468 and 1357 have no digits in common
```

```
Please input two numbers: 0 105
Digits in both 0 and 105: 0
```
