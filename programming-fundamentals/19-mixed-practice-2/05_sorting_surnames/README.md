# Sorting Surnames

Reads a list of full names and sorts them by surname with an insertion sort. Names with the same surname are ordered by the full name. The surname is the last word of the name.

## Run

```bash
javac SortingSurnames.java
java SortingSurnames
```

## Example run

```
How many names? 5
Name 1: Sean Kelly
Name 2: Aoife Byrne
Name 3: Anne Kelly
Name 4: Padraig O'Neill
Name 5: Grace Adams
Sorted by surname:
  Grace Adams
  Aoife Byrne
  Anne Kelly
  Sean Kelly
  Padraig O'Neill
```
