# Mixed revision

Revision exercises that combine digits, strings, sorting and an `ArrayList`. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Common Digit | [01_common_digit](01_common_digit/) | Prints the digits two numbers have in common. |
| 2. Reverse String 2 | [02_reverse_string_2](02_reverse_string_2/) | Reverses the order of the words in a sentence. |
| 3. Caesar Cipher | [03_caesar_cipher](03_caesar_cipher/) | Encrypts or decrypts a message with one `shift` method that handles both directions. |
| 4. Pentagons | [04_pentagons](04_pentagons/) | Prints the first n pentagonal numbers, n(3n − 1)/2. |
| 5. Sorting Surnames | [05_sorting_surnames](05_sorting_surnames/) | Sorts full names by surname, then by first name, with an insertion sort. |
| 6. County Wins | [06_county_wins](06_county_wins/) | Tallies wins per county from a list of winners and sorts by number of wins. |
