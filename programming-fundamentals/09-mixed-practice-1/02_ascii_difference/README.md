# ASCII Difference

Reads two characters and prints their ASCII values and the difference between them, always as a positive number.

## Run

```bash
javac ASCIIDifference.java
java ASCIIDifference
```

## Example runs

```
Please input two characters: a d
a has ASCII value 97
d has ASCII value 100
Difference: 3
```

```
Please input two characters: Z A
Z has ASCII value 90
A has ASCII value 65
Difference: 25
```
