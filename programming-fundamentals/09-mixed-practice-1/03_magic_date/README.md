# Magic Date

A date is magic when the day times the month equals the last two digits of the year, eg. 6/10/1960. Reads day, month and year and says whether it is.

## Run

```bash
javac MagicDate.java
java MagicDate
```

## Example runs

```
Please input a day, month and year: 6 10 1960
6/10/1960 is a magic date
```

```
Please input a day, month and year: 7 8 2024
7/8/2024 is not a magic date
```

```
Please input a day, month and year: 32 1 2000
Invalid date
```
