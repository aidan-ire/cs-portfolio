# Lab 09: Mixed revision

Exercises on a mix of the earlier topics. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Hourly Rates | [01_hourly_rates](01_hourly_rates/) | Reads hours worked and an hourly rate. The first 40 hours are paid at the rate and any hours over 40 at one and a half times the rate. |
| 2. ASCII Difference | [02_ascii_difference](02_ascii_difference/) | Reads two characters and prints their ASCII values and the difference between them, always as a positive number. |
| 3. Magic Date | [03_magic_date](03_magic_date/) | A date is magic when the day times the month equals the last two digits of the year, eg. 6/10/1960. Reads day, month and year and says whether it is. |
| 4. Decode | [04_decode](04_decode/) | Treats the message as a Caesar cipher. Reads the message and the shift it was encoded with, and shifts each letter back by that amount. Case is kept, and other characters are left alone. |
