# Hourly Rates

Reads hours worked and an hourly rate. The first 40 hours are paid at the rate and any hours over 40 at one and a half times the rate.

## Run

```bash
javac HourlyRates.java
java HourlyRates
```

## Example runs

```
Please input the hours worked and the hourly rate: 35 12.50
Pay: 437.50
```

```
Please input the hours worked and the hourly rate: 45 10
Pay: 475.00
```
