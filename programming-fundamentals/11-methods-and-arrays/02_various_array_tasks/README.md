# Various Array Tasks

Reads an array of whole numbers and passes it to a separate method for each task: sum, average, largest, smallest and how many are even.

## Run

```bash
javac VariousArrayTasks.java
java VariousArrayTasks
```

## Example run

```
Please input the number of values: 6
Please input the values: 4 -7 12 9 0 3
Sum: 21
Average: 3.50
Max: 12
Min: -7
Even numbers: 3
```
