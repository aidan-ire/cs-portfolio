# Linear Search 2

A linear search that finds every position of a number, not just the first. `findAll` returns an array of the matching indexes, which is empty when there is no match.

## Run

```bash
javac LinearSearch2.java
java LinearSearch2
```

## Example runs

```
Array: [4, 8, 15, 4, 16, 23, 4, 42, 8, 15]
Please input a number to search for: 4
4 appears 3 times, at indexes 0, 3, 6
```

```
Array: [4, 8, 15, 4, 16, 23, 4, 42, 8, 15]
Please input a number to search for: 42
42 appears once, at index 7
```

```
Array: [4, 8, 15, 4, 16, 23, 4, 42, 8, 15]
Please input a number to search for: 5
5 is not in the array
```
