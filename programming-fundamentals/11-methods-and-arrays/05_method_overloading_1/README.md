# Method Overloading 1

Four `max` methods with the same name and different parameters: two `int`s, two `double`s, three `int`s and two `String`s. Java chooses which one to call from the arguments. The program takes no input.

## Run

```bash
javac MethodOverloading1.java
java MethodOverloading1
```

## Example run

```
max(3, 9) = 9
max(2.5, 1.75) = 2.5
max(4, 11, 7) = 11
max("apple", "pear") = pear
```
