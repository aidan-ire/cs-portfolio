# Factorial

Reads a number and prints its factorial using a `factorial` method that returns a `long`. Only 0–20 is accepted, because 21! is too big for a `long`.

## Run

```bash
javac Factorial.java
java Factorial
```

## Example runs

```
Please input a number (0-20): 5
5! = 120
```

```
Please input a number (0-20): 20
20! = 2432902008176640000
```

```
Please input a number (0-20): 21
The number must be between 0 and 20
```
