# Methods and arrays

Methods that take and return arrays, two kinds of linear search, and method overloading. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Factorial | [01_factorial](01_factorial/) | Prints n! for 0–20 using a method that returns a `long`. |
| 2. Various Array Tasks | [02_various_array_tasks](02_various_array_tasks/) | Sum, average, largest, smallest and number of even values in an array, one method per task. |
| 3. Linear Search 1 | [03_linear_search_1](03_linear_search_1/) | Returns the index of the first match in an array, or -1. |
| 4. Linear Search 2 | [04_linear_search_2](04_linear_search_2/) | Returns every index where a number appears. |
| 5. Method Overloading 1 | [05_method_overloading_1](05_method_overloading_1/) | Four `max` methods with the same name and different parameter lists. |
