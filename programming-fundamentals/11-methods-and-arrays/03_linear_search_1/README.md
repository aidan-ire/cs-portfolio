# Linear Search 1

Searches a fixed array for a number entered by the user with a `linearSearch` method. The method returns the index of the first match, or -1 if the number isn't there.

## Run

```bash
javac LinearSearch1.java
java LinearSearch1
```

## Example runs

```
Array: [12, 45, 7, 23, 56, 89, 34, 7, 91, 18]
Please input a number to search for: 7
7 found at index 2
```

```
Array: [12, 45, 7, 23, 56, 89, 34, 7, 91, 18]
Please input a number to search for: 50
50 is not in the array
```
