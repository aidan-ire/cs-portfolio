# Strings and arrays

String building, digit grouping and counting, with arrays used for results and tallies. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Combine Reverse | [01_combine_reverse](01_combine_reverse/) | Prints the second string reversed followed by the first string reversed. |
| 2. Comma Numbers | [02_comma_numbers](02_comma_numbers/) | Adds thousands separators to a whole number, eg. `1234567` → `1,234,567`, without `String.format`. |
| 3. Mexican Wave | [03_mexican_wave](03_mexican_wave/) | Prints a word once per letter with that letter capitalised. |
| 4. Five or More | [04_five_or_more](04_five_or_more/) | Reads numbers until 0 and counts how many are 5 or more. |
| 5. Poker Hand | [05_poker_hand](05_poker_hand/) | Names the poker hand made by five cards, from straight flush down to high card. |
| 6. ASCII Difference | [06_ascii_difference](06_ascii_difference/) | Prints the ASCII difference between each pair of neighbouring characters in a word. |
| 7. Add As | [07_add_as](07_add_as/) | Counts the `a`s and `A`s in a sentence. |
