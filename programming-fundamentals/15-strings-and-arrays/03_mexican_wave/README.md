# Mexican Wave

Reads a word or phrase and prints one copy for each letter, with that letter alone in upper case. Spaces and other non-letters are skipped, since they have no capital.

## Run

```bash
javac MexicanWave.java
java MexicanWave
```

## Example runs

```
Please input a word or phrase: hello
Hello
hEllo
heLlo
helLo
hellO
```

```
Please input a word or phrase: go team
Go team
gO team
go Team
go tEam
go teAm
go teaM
```
