# Arrays

Exercises on arrays of numbers and strings, searching them and swapping values. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Heights | [01_heights](01_heights/) | Reads five heights (in metres) into an array and prints the tallest, the shortest and the average. |
| 2. Dot Product | [02_dot_product](02_dot_product/) | Reads the length, then two vectors of that length, and prints the sum of the products of matching positions. |
| 3. String Array | [03_string_array](03_string_array/) | Declares an array of five fruit names, prints each with its index, prints the longest name and then prints the array in reverse. |
| 4. Array Value Swap | [04_array_value_swap](04_array_value_swap/) | Reads two positions and swaps the values at those positions in the array `10 20 30 40 50`, printing it before and after. Positions outside the array are rejected. |
| 5. Find Negatives | [05_find_negatives](05_find_negatives/) | Reads how many numbers there are and then the numbers, and prints the negative ones and how many there were. |
| 6. License Plates 2 | [06_license_plates_2](06_license_plates_2/) | Reads a plate like `191-D-12345` and finds its county code in an array of codes, printing the county at the same position in a second array. It covers the 25 county codes in use since 2014. |
