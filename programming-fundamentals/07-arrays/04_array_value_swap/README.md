# Array Value Swap

Reads two positions and swaps the values at those positions in the array `10 20 30 40 50`, printing it before and after. Positions outside the array are rejected.

## Run

```bash
javac ArrayValueSwap.java
java ArrayValueSwap
```

## Example runs

```
Please input two positions (0 to 4): 0 4
Before: 10 20 30 40 50
After: 50 20 30 40 10
```

```
Please input two positions (0 to 4): 1 9
Position out of range
```
