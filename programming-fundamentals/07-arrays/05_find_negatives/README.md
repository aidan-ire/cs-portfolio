# Find Negatives

Reads how many numbers there are and then the numbers, and prints the negative ones and how many there were.

## Run

```bash
javac FindNegatives.java
java FindNegatives
```

## Example runs

```
Please input how many numbers there are: 6
Please input the numbers: 4 -2 7 -9 0 -1
Negative numbers: -2 -9 -1
Count: 3
```

```
Please input how many numbers there are: 3
Please input the numbers: 1 2 3
No negative numbers
```
