# Dot Product

Reads the length, then two vectors of that length, and prints the sum of the products of matching positions.

## Run

```bash
javac DotProduct.java
java DotProduct
```

## Example run

```
Please input the length of the vectors: 3
Please input the first vector: 1 2 3
Please input the second vector: 4 5 6
Dot product: 32
```
