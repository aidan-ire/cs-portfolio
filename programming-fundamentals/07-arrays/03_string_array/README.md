# String Array

Declares an array of five fruit names, prints each with its index, prints the longest name and then prints the array in reverse.

## Run

```bash
javac StringArray.java
java StringArray
```

## Example run

```
0: apple
1: banana
2: cherry
3: date
4: elderberry
Longest: elderberry
In reverse:
elderberry
date
cherry
banana
apple
```
