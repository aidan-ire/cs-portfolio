# Strings

Exercises on `String` methods and walking through a string character by character. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Strings 1 | [01_strings_1](01_strings_1/) | Reads a word and prints its length, first and last characters, and its upper and lower case forms. |
| 2. Strings 2 | [02_strings_2](02_strings_2/) | Reads a sentence and prints its first word (`indexOf`, `substring`), whether it contains "java" (`contains`) and the sentence with spaces replaced by underscores (`replace`). |
| 3. Reverse String | [03_reverse_string](03_reverse_string/) | Reads a line and builds the reversed string with a loop from the last character to the first. |
| 4. Compare Strings | [04_compare_strings](04_compare_strings/) | Reads two words and says whether they are identical, the same apart from case, or which one comes first alphabetically (`compareTo`). |
| 5. Palindromes | [05_palindromes](05_palindromes/) | Reads a line, keeps only its letters in lower case, and checks they read the same in both directions. Spaces, digits and punctuation are ignored. |
| 6. Eircode | [06_eircode](06_eircode/) | Checks the format only: a routing key (a letter and two digits, or `D6W`) then four letters or digits, with an optional space between. The routing key is not looked up against the real list. |
| 7. Backwards Sentence | [07_backwards_sentence](07_backwards_sentence/) | Reads a line, splits it into words and prints them from last to first, separated by single spaces. The letters inside each word are not reversed. |
| 8. Spaces | [08_spaces](08_spaces/) | Reads a line and prints how many spaces it has and what it looks like with all the spaces removed. |
