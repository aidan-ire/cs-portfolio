# Compare Strings

Reads two words and says whether they are identical, the same apart from case, or which one comes first alphabetically (`compareTo`).

## Run

```bash
javac CompareStrings.java
java CompareStrings
```

## Example runs

```
Please input two words: apple apple
The words are identical
```

```
Please input two words: Apple apple
The words are the same apart from case
```

```
Please input two words: pear apple
apple comes before pear
```
