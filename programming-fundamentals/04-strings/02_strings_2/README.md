# Strings 2

Reads a sentence and prints its first word (`indexOf`, `substring`), whether it contains "java" (`contains`) and the sentence with spaces replaced by underscores (`replace`).

## Run

```bash
javac Strings2.java
java Strings2
```

## Example runs

```
Please input a sentence: I like Java a lot
First word: I
Contains "java": true
Spaces replaced: I_like_Java_a_lot
```

```
Please input a sentence: hello
First word: hello
Contains "java": false
Spaces replaced: hello
```
