# Palindromes

Reads a line, keeps only its letters in lower case, and checks they read the same in both directions. Spaces, digits and punctuation are ignored.

## Run

```bash
javac Palindromes.java
java Palindromes
```

## Example runs

```
Please input a word or phrase: Racecar
It is a palindrome
```

```
Please input a word or phrase: A man, a plan, a canal: Panama
It is a palindrome
```

```
Please input a word or phrase: Dublin
It is not a palindrome
```
