# Lab 01: Revision and methods

Revision of first-year topics, with each program's main logic moved into a `public static` method called from `main`. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. Seasons | [01_seasons](01_seasons/) | Reads a month number (1–12) and prints its meteorological season, rejecting anything outside that range. |
| 2. Star Triangle | [02_star_triangle](02_star_triangle/) | Reads a height and prints a centred triangle of stars, with row `i` having `2i - 1` stars. |
| 3. Double Size | [03_double_size](03_double_size/) | Reads an array and returns a new one twice as long, with the original values at the front and 0s after them. |
| 4. Palindromes | [04_palindromes](04_palindromes/) | Checks whether a word reads the same backwards, ignoring case. |
| 5. Primes | [05_primes](05_primes/) | Prints every prime up to a limit and how many there are. |
| 6. Prime Palindrome | [06_prime_palindrome](06_prime_palindrome/) | Prints every number up to a limit that is both prime and a palindrome, eg. 131. |
