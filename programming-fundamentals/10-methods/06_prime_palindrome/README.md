# Prime Palindrome

Reads a limit and prints every number up to it that is both prime and a palindrome, such as 131. It uses an `isPrime` method and an `isPalindrome` method that reverses the number digit by digit.

## Run

```bash
javac PrimePalindrome.java
java PrimePalindrome
```

## Example runs

```
Please input a limit: 200
Prime palindromes up to 200: 2 3 5 7 11 101 131 151 181 191
```

```
Please input a limit: 1000
Prime palindromes up to 1000: 2 3 5 7 11 101 131 151 181 191 313 353 373 383 727 757 787 797 919 929
```
