# Star Triangle

Reads a height and prints a centred triangle of stars from a `printTriangle` method. Row `i` has `2i - 1` stars, with spaces in front to keep it centred.

## Run

```bash
javac StarTriangle.java
java StarTriangle
```

## Example run

```
Please input a height: 4
   *
  ***
 *****
*******
```
