# Palindromes

Reads a word and checks it with an `isPalindrome` method. The method compares letters from both ends, moving inwards, and ignores case.

## Run

```bash
javac Palindromes.java
java Palindromes
```

## Example runs

```
Please input a word: Racecar
Racecar is a palindrome
```

```
Please input a word: Dublin
Dublin is not a palindrome
```
