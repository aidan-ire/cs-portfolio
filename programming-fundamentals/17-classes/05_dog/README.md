# Dog

A `Dog` class with a name, breed and age, plus `bark`, `haveBirthday` and `humanYears` methods. Human years count 15 for the first year, 9 for the second and 5 for each year after.

## Files

- `Dog.java` — the class
- `TestDog.java` — creates two dogs and compares their ages

## Run

```bash
javac *.java
java TestDog
```

## Example run

```
Rex the Labrador, 1 year old
Rex says Woof!
In human years: 15
After a birthday: Rex the Labrador, 2 years old, 24 in human years
Bella the Border Collie, 7 years old
Bella says Woof!
In human years: 49
Bella is older
```
