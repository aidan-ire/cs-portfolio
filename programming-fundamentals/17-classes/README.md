# Classes

Writing classes with private fields, constructors, getters and setters that validate their input, and methods that work on the object's state. Each folder holds the class, a `Test…` class with a `main` that uses it, and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. BasicCircle Class | [01_basic_circle_class](01_basic_circle_class/) | A circle with a validated radius, plus diameter, area and circumference. |
| 2. BasicSquare Class | [02_basic_square_class](02_basic_square_class/) | A square with a validated side, plus area, perimeter, diagonal and a size comparison. |
| 3. Dice | [03_dice](03_dice/) | A die with any number of sides that rolls with `Random`, tested over 60,000 rolls. |
| 4. Employee | [04_employee](04_employee/) | An employee with a salary that can be raised by a percentage, used in an array. |
| 5. Dog | [05_dog](05_dog/) | A dog with a name, breed and age, birthdays and an age in human years. |
| 6. Bank Account | [06_bank_account](06_bank_account/) | An account that can't go overdrawn, with a deposit/withdraw menu. |
