# Valid Name

Asks for a full name until it is valid: 2–30 characters, starting and ending with a letter, with single spaces, hyphens or apostrophes allowed between letters.

## Run

```bash
javac ValidName.java
java ValidName
```

## Example run

```
Please input your full name: J
Invalid name. Use 2-30 letters, with single spaces, hyphens or apostrophes between them.
Please input your full name: Sean  Kelly
Invalid name. Use 2-30 letters, with single spaces, hyphens or apostrophes between them.
Please input your full name: R2D2
Invalid name. Use 2-30 letters, with single spaces, hyphens or apostrophes between them.
Please input your full name: Mary-Kate O'Brien
Hello, Mary-Kate O'Brien
```
