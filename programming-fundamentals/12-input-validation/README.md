# Input validation

Programs that check what the user types and keep asking until the input is acceptable, either by checking each character or by using `Scanner.hasNextInt`. Each folder holds one class and a short README with how to run it and an example run.

| Exercise | Folder | What it does |
|---|---|---|
| 1. String Acceptance | [01_string_acceptance](01_string_acceptance/) | Asks until a word of 5–10 letters (letters only) is entered. |
| 2. Which Expression | [02_which_expression](02_which_expression/) | Reads three validated whole numbers and says which of `a + b * c`, `a * b + c` and `(a + b) * c` is largest. |
| 3. Valid Age | [03_valid_age](03_valid_age/) | Asks until a whole number age from 0 to 120 is entered. |
| 4. Valid Name | [04_valid_name](04_valid_name/) | Asks until a name of letters with single spaces, hyphens or apostrophes is entered. |
| 5. Flight Codes | [05_flight_codes](05_flight_codes/) | Asks until a code of two uppercase letters and 3–4 digits is entered, eg. `EI123`. |
| 6. Genomes | [06_genomes](06_genomes/) | Asks until a DNA strand of only A, C, G and T is entered, then prints its complement. |
| 7. Alarm | [07_alarm](07_alarm/) | Adds minutes to a validated `hh:mm` time, wrapping past midnight. |
| 8. Password | [08_password](08_password/) | Asks until a password meets every rule, listing each rule that a rejected password breaks. |
