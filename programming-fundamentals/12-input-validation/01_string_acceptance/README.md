# String Acceptance

Keeps asking for a word until it is 5–10 letters long with nothing but letters, then accepts it. The check is done in an `isAcceptable` method.

## Run

```bash
javac StringAcceptance.java
java StringAcceptance
```

## Example run

```
Please input a word of 5-10 letters: hi
Not accepted, it must be 5-10 letters only. Try again: hello123
Not accepted, it must be 5-10 letters only. Try again: Dublin
Accepted: Dublin
```
