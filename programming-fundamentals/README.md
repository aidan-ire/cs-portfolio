# Programming fundamentals (Java)

Short Java exercises that build up from printing and variables to classes and inheritance. Each
topic folder has a README listing its exercises, and each exercise has its own folder with one
program (or a class and a test driver) and a README with an example run. These come from my
first-year programming modules (CS161 and CS162).

| Topic | Exercises | What it covers |
|---|---|---|
| [01-variables-and-output](01-variables-and-output/) | 6 | printing, variables, arithmetic and the modulus operator |
| [02-selection](02-selection/) | 6 | `if`/`else`, `switch` and the ternary operator: retirement age, licence categories, a calculator, leap years, FizzBuzz |
| [03-loops](03-loops/) | 6 | `for` and `while` loops: counting, FizzBuzz, divisors, prime checking, palindromic numbers |
| [04-strings](04-strings/) | 8 | `String` methods: reversing, comparing, palindromes, Eircode validation, sentence handling |
| [05-keyboard-input](05-keyboard-input/) | 8 | reading numbers and text with `Scanner`: text speak, licence plates, the middle number |
| [06-loops-and-strings](06-loops-and-strings/) | 6 | loops over strings: triangles, reversed substrings, mirrors, self-factoring numbers, module code validation |
| [07-arrays](07-arrays/) | 6 | one-dimensional arrays: heights, dot product, swapping values, finding negatives |
| [08-nested-loops-and-2d-arrays](08-nested-loops-and-2d-arrays/) | 6 | nested loops and 2D arrays: smallest row, filling a diagonal, factorial sums, flattening |
| [09-mixed-practice-1](09-mixed-practice-1/) | 4 | mixed practice: hourly rates, ASCII differences, magic dates, decoding |
| [10-methods](10-methods/) | 6 | moving logic into static methods: seasons, star triangles, palindromes, primes |
| [11-methods-and-arrays](11-methods-and-arrays/) | 5 | methods over arrays: factorial, array tasks, linear search, method overloading |
| [12-input-validation](12-input-validation/) | 8 | re-prompting until input is valid: ages, names, flight codes, DNA strings, alarm times, passwords |
| [13-recursion](13-recursion/) | 7 | recursive methods: minimum value, string reverse, digit sums, cleaning strings, counting vowels |
| [14-methods-and-recursion](14-methods-and-recursion/) | 5 | more recursion and overloading: substrings, exponents, reciprocals, removing odd numbers |
| [15-strings-and-arrays](15-strings-and-arrays/) | 7 | string and array processing: comma numbers, the Mexican wave, poker hands, ASCII differences |
| [16-searching-and-sorting](16-searching-and-sorting/) | 7 | hand-written searching and sorting: anagrams, binary search game, bubble sort, unique sorting |
| [17-classes](17-classes/) | 6 | writing classes with fields, constructors and methods: circles, squares, dice, employees, bank accounts |
| [18-inheritance](18-inheritance/) | 6 | subclasses and overriding: people and students, vehicles, animals, account types |
| [19-mixed-practice-2](19-mixed-practice-2/) | 6 | mixed practice: common digits, Caesar cipher, pentagonal numbers, sorting surnames, county wins |

## Running an exercise

```bash
cd programming-fundamentals/03-loops/04_divisors
javac *.java
java Divisors
```
