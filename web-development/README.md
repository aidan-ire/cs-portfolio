# Web development (HTML, CSS, JavaScript, Node.js)

From static pages to a full-stack app. Frontends use plain HTML, CSS and JavaScript with no
frameworks; backends use Express and SQLite. These come from my second-year web module (CS230).

| Type | Project | What it covers |
|---|---|---|
| Frontend | [Mini profile site](frontend/mini-profile-site/) | a two-page site in HTML and CSS with a contact form |
| Frontend | [Responsive study dashboard](frontend/responsive-study-dashboard/) | a responsive single-page dashboard with small JavaScript interactions |
| Frontend | [Countdown timer](frontend/countdown-timer/) | a start/pause/stop timer with DOM updates and `setInterval` |
| Backend | [Book management API](backend/book-management-api/) | a REST API with Express and SQLite: CRUD, filtering, validation and 404s |
| Full stack | [Music library](full-stack/music-library/) | artists, albums and songs: an Express and SQLite API with a plain JavaScript frontend |

Node projects: run `npm install` and then `npm start` (or `node server.js`) inside the folder.
