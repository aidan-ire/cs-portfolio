# Algorithms and data structures (Java)

Classic algorithms and data structures in Java. Most projects pair a pen-and-paper exercise (worked
in the README) with a program. They come from my second-year algorithms modules (CS210 and CS211),
plus two short problems from a third-year module (CS310).

| Topic | Project | What it covers |
|---|---|---|
| Sorting | [Sorting algorithms](sorting/sorting-integers-strings-customers/) | bubble, insertion and selection sort on integers, strings and `Customer` objects, with swap counts |
| Sorting | [Quicksort](sorting/quicksort/) | hand-written quicksort, plus a traced example |
| Searching | [Array search and magic square](searching/array-search-and-magic-square/) | linear vs binary search timing, array palindromes, magic squares |
| Recursion | [Recursive functions](recursion/recursive-functions/) | recursive sum, reverse, palindrome and power, timed against a loop |
| Linked lists and hashing | [Reverse a linked list](linked-lists-and-hashing/reverse-linked-list/) | reversing a singly linked list in place |
| Linked lists and hashing | [Linked list and word count](linked-lists-and-hashing/linked-list-and-word-count/) | linked list operations and a `HashMap` word count of a novel |
| Trees | [Binary search tree](trees/binary-search-tree/) | insertion, height and traversals |
| Trees | [AVL tree and minimum depth](trees/avl-tree-and-min-depth/) | worked AVL rotations and the minimum depth of a binary tree |
| Graphs | [Airport route graph](graphs/airport-route-graph/) | adjacency-list graph analysis: degree, reach and hub removal |
| Graphs | [Dijkstra and longest common prefix](graphs/dijkstra-and-longest-common-prefix/) | a worked shortest path and the longest common prefix of a word list |
| Strings | [KMP string search](strings/kmp-string-search/) | naive search and the KMP partial match table |
| Compression | [Huffman and run-length encoding](compression/huffman-and-run-length-encoding/) | a worked Huffman code and a run-length encoder |
| Cryptography | [ElGamal encryption](cryptography/elgamal-encryption/) | ElGamal encryption and breaking a small key |
| Bit manipulation | [Bitwise operations](bit-manipulation/bitwise-operations/) | evaluating bitwise expressions and reversing the bits of an integer |
| Number theory | [Sieve and Goldbach](number-theory/sieve-and-goldbach/) | the Sieve of Eratosthenes and checking the Goldbach conjecture |
| Stacks and scheduling | [CPU scheduling and stacks](stacks-and-scheduling/cpu-scheduling-and-stack-palindrome/) | worked FCFS, SJF, SRTF, Round Robin and priority schedules, and a stack palindrome checker |
| Simulation | [Monte Carlo simulation](simulation/monte-carlo/) | estimating probabilities by simulation: coin flips, poker hands, random walks |
| Coding problems | [Palindrome and two sum](coding-problems/palindrome-and-two-sum/) | two short interview-style problems |
